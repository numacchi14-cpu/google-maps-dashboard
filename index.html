スポット帖について（詳しい説明）

NUM-ISH運営者の菱沼政彦が個人で開発・運営しています。 通常のデータ処理は利用者のブラウザ内で行われ、運営者が管理するサーバーへ送信されることはありません。 利用者がGoogle Drive連携を選択した場合に限り、バックアップデータは利用者のブラウザからGoogle Driveへ直接送信されます。

主な機能：Google Takeoutから書き出した利用者自身のデータの読み込み／保存した場所やクチコミの検索・分類／地図やグラフによる可視化／ローカルデータの編集・バックアップ／任意のGoogleドライブ連携。 Googleマップに蓄積した自分自身の記録を整理し、場所・クチコミ・評価・行動の傾向などを振り返りたい方を対象としています。

Googleドライブ連携について（詳しい説明）

  • Googleドライブ連携は任意

  • スポット帖が作成するバックアップファイルを、利用者自身のGoogleドライブへ保存・読み込みするためだけに使用
  • Google Drive全体へのアクセス権は要求しない
  • 氏名、メールアドレス、プロフィール情報は取得しない
  • 広告利用、データ販売、目的外の第三者提供は行わない

About スポット帖 (Spot-cho) and Google Drive Integration

スポット帖 (Spot-cho) is a personal web application that helps users organize and visualize their own Google Maps records. Optional Google Drive integration uses the drive.file scope only to save and restore the backup file created by the app. The app does not request access to the user's entire Google Drive.

ログを手動で追加

Google Takeoutの口コミエクスポートには件数の上限があり、漏れてしまったクチコミが出ることがあります。ここで直接追加すれば、他のデータと同じように一覧・グラフ・地図に反映されます（保存後、都道府県・カテゴリーの手動編集も可能です）。 追加した内容はこのアプリ内だけの記録です。Googleマップ本体への投稿・反映は行われません。

複数件をまとめて編集したい場合は、手動入力データをCSVでエクスポート→Excel等で編集→再度読み込む、という使い方もできます。「ID」列が既存データと一致する行は上書き、空欄の行は新規追加されます。

マイカテゴリーの管理

Google連動カテゴリー（自動判定／Geminiで取得した実データ）とは別に、自分だけのカテゴリーを作成できます。作成したカテゴリーは各スポットの「マイカテゴリー」欄で選択でき、フィルター・グラフにも反映されます。

Google連動カテゴリーをGeminiで調べる

スポット名・住所のみをGeminiに渡して業種を判定してもらい、返ってきた業種ラベルをそのままGoogle連動カテゴリーとして反映します（12種類への丸め込みはしません。評価・レビュー本文は送信されません）。 「①プロンプトをコピー」→「②Geminiに貼り付けて実行」→「③返ってきたJSONをここに貼り付けて適用」の3ステップです。件数が多い場合は複数回に分けて繰り返してください。

不明なスポットの確認

今回読み込んだデータの中に、Google側からスポット名を取得できなかった項目があります（閉店・削除済みのスポットなどでよく発生します）。 削除したいものにチェックを入れて「選択した項目を削除」を押してください。何もしなければ一覧にそのまま残ります。

削除済みスポット

一覧から削除したスポットはここに残ります。誤って削除した場合は「復元する」で一覧に戻せます。 ここにある間は、Google Takeoutなどを再読み込みしても自動的には復活しません。「完全に削除」を押すと、以後の再インポートで復活しうる状態に戻ります。

リンク・緯度経度 要確認

「リンク・緯度経度をGeminiで調べる」に関連して、手動での確認・操作が必要なスポットをまとめて表示します。 ①座標の食い違い：住所から判定した都道府県と座標から判定した都道府県が食い違っていたスポットです。地図や住所と照らし合わせて問題なければ「確認OK」を押してください（座標やスポット自体は変更されず、フラグだけが外れます）。 ②Geminiが見つけられなかったスポット：前回のバッチでGeminiが情報を返せなかったため、以後の自動バッチ対象から外れています。もう一度試したい場合は「もう一度調べる対象に含める」を押してください。

重複候補の確認

同じスポット名・同じ都道府県で、住所が異なる行をグループごとに表示します。店舗の移転などで、同じ場所が別レコードとして重複登録されている可能性があります （Google側で移転すると別の場所として扱われ、Takeoutでも別レコードとしてエクスポートされるため、既存の重複排除では1件にまとまりません）。 内容を確認し、不要な方（例: 移転前の古い住所）を「削除」してください（削除しても「削除済みスポット」から復元できます）。
